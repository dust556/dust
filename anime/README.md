# anime/

## benijin/ — 紅刃 BENIJIN（第壱話 黄昏ノ廃都）

Three.js で作ったスタイリッシュアクションの3DCG短編（約32秒・12カット）。
`benijin/index.html` をブラウザで開くと、その場でリアルタイムに描画されます（Three.js は CDN から読み込み）。

- トゥーンシェーディング＋背面法アウトライン
- インパクトフレーム（白黒反転）、ヒットストップ、バレットタイム
- 集中線・流線（24コマ単位で描き直し）、残像、技名テロップ
- WebAudio で合成した効果音（画面下の「効果音」ボタンでオン）

カットは `CUTS` 配列に1カット1関数で定義してあり、各関数がその時刻のカメラ・ポーズ・エフェクトを決めます。
時刻から状態を毎フレーム決定的に計算するので、シークバーでどこへ飛んでも同じ絵になります。

## noctis/ — NOCTIS ティザーPV（15秒・14カット）

雨の夜の近未来都市を舞台にしたアーバンファンタジーのティザー。`noctis/index.html` をブラウザで開くと再生されます。

- 登場人物：レン（青く光る黒環）、ユキ（赤いワイヤー）、カイ（紫の重力）、シオン（緑の音波）、オルフェ（黒い影と金の光輪）
- 濡れた屋上の平面反射、ブルーム、雨とその波紋、重力レンズ風の歪み
- 映像内の文字は最後のタイトル「NOCTIS」だけ
